<h1>Olá, esse é um projeto que fiz em grupo com uns amigos da faculdade.</h1>

<p>Aqui criamos um sistema para gerenciamento de estoque e vendas de produtos a fim de aprofundar os nossos conhecimentos em programação, usando a linguagem C.</p>

<h3>Alguns aprendizados importantes:</h3>
<ul>
  <li>Manipular dados, salvar em arquivos .txt e em binários .dat.</li>
  <li>Modularização do código</li>
  <li>Documentação</li>
  <li>Lógica de programação</li>
  <li>Trabalho em equipe</li>
  <li>Metodologia SCRUM</li>
</ul>
